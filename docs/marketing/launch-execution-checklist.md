# DataAgent — Launch Execution Checklist + Content Calendar

**Purpose:** The day-by-day operating version of `30-day-plan.md`. Use this at the desk; use the other docs for strategy and copy.

**Companion docs:** `30-day-plan.md`, `preflight-checklist.md`, `claim-audit.md`, `insta-youtube-captions.md`, `ai-video-prompts.md`.

**Launch:** Monday 2 November 2026. **Owner:** Solo founder. **Time:** 7–9 h/week.

**North star:** Pro trial starts per week. **Primary CTA:** Free Windows download + 14-day Pro trial, no card → `https://data-agent.me/download`.

## 5. Per-Post QA (30 seconds before scheduling)

- [ ] First frame is proof — `.pbix`, messy CSV, Wi-Fi off, or DAX. Not a logo.
- [ ] Hook lands in ≤1.5 s; cut every 2–4 s; one proof shot per 5 s.
- [ ] 9:16, 1080×1920, burned-in captions; safe zones clear.
- [ ] One idea, one CTA.
- [ ] Says Windows 10/11 x64 where relevant.
- [ ] Says `.pbix` export/import is Pro and the 14-day trial unlocks it.
- [ ] No forbidden phrase: free `.pbix`, unlimited, 100% private, zero telemetry, open source, Mac/Linux, replaces Power BI, no internet needed, GDPR/HIPAA, AI does everything.
- [ ] AI disclosure added if an avatar appears.
- [ ] Caption links `https://data-agent.me/download`, not the website repo.
- [ ] Pinned comment ready with trial link + one install tip.
- [ ] 5–8 targeted hashtags (one full set + 1–2 from another).

**Friday decision rules**
- 3-second view rate < 50% → rewrite hooks; show the proof in frame one.
- High views, low profile visits → stronger verbal CTA + on-screen handle.
- High profile visits, low link clicks → fix bio and pinned post.
- High downloads, low trials → improve the install video's "what next" step and in-app trial prompt.
- High trials, low paid → interview 3 trial users; inspect the trial-end moment.
- One format wins twice → make two more of it before inventing anything new.

**Weekly review sentence:** "Next week I will do more of ___ and less of ___."

## 8. If Something Breaks

| Situation | Action |
|---|---|
| A P0 gate fails | Delay launch; post nothing until it is green. |
| Trial or `.pbix` export fails mid-week | Pull scheduled posts; publish the install/FAQ short instead. |
| Negative "AI slop" comment | Reply with a screen recording, not a debate; pin the best proof. |
| Week slips | Publish from the 2-short buffer; cut one post; do not skip QA. |
| Views are fine, trials are not | Stop producing; fix the profile → download → trial path first. |
